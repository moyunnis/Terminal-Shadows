# Terminal Shadows

Текстовая игра для терминала. Ты — хакер-одиночка, который разбирает дела
умершего дяди и постепенно упирается в то, во что упираться не стоило.

Рядом с тобой всё время Гид — программа-ассистент, которую дядя собирал годами.
Гид помогает, но он не человек, и это заметно: память с провалами, речь то сухая,
то странная, свои мысли на уме. Что он такое на самом деле — выясняется по ходу.

Игра на русском, работает в терминале. Есть сюжет на 40 глав и свободный режим.

## Установка

Нужен Python 3.8 или новее.

Linux / macOS:

```bash
git clone https://github.com/moyunni/Terminal-Shadows.git
cd Terminal-Shadows
./install.sh
./run_game.sh
```

Windows: скачай архив, распакуй, запусти `install.bat`, потом `run_game.bat`.

`install` создаёт локальное окружение и ставит зависимость (colorama).
Если не хочешь возиться со скриптами — можно просто:

```bash
pip install -r requirements.txt
python main.py
```

## Как играть

Управление — цифры и Enter. Всё меню и выборы выбираются номером.

- **Сюжет** — 40 глав. Выборы влияют на то, как складывается путь и чем всё
  кончится. Концовок несколько, и все они человеческого масштаба.
- **Свободный режим** — без сюжета: цели для взлома, барахолка с инструментами,
  системы защиты, сборка своих штук, случайные события, репутация с разными
  группами в городе.

Игра сохраняется сама после каждой главы. Есть ручные слоты. Сохранения лежат в
`~/.terminal_shadows/` (на Windows — в профиле пользователя).

## Обновление

```bash
./update_game.sh        # Windows: update_game.bat
```

Апдейтер тянет свежую версию из репозитория и не трогает твои сохранения.

## Структура

```
main.py            движок: меню, режимы, механики
updater.py         обновление из git
version.txt        текущая версия
data/ascii_arts/   заставки
story/             главы сюжета, по файлу на главу (chapterN.py)
scripts/           валидатор глав для разработки
```

## Своя глава

Каждая глава — обычный python-словарь. Минимальный пример:

```python
CHAPTER_41 = {
    "title": "Глава 41: Название",
    "guide_appearance": True,   # показывать ли Гида в начале главы
    "scenes": {
        "start": {
            "text": "Текст сцены.",
            "choices": [
                {"text": "Что-то сделать", "next": "s2",
                 "effect": {"bitcoins": 500, "exp": 200}},
                {"text": "Уйти", "next": "chapter_end", "effect": {}},
            ],
        },
        "s2": {
            "text": "Продолжение.",
            "choices": [{"text": "Дальше", "next": "chapter_end", "effect": {}}],
        },
    },
}
```

Движок сам подхватывает файлы `chapterN.py` из `story/` по порядку номеров.
`effect` понимает ключи: `bitcoins`, `exp`, `skill` (+`value`), `item`,
`reputation`, `achievement`. Выход из главы — `next: "chapter_end"`; у последней
главы финал ведёт в `game_end`.

Проверить, что все главы не сломаны:

```bash
python scripts/validate_chapters.py
```
